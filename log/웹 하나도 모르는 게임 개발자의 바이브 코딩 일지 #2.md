## 🎮 Prologue : Phase 1 & 2는 그저 튜토리얼이었다

지난 편에서 CRT 효과, 부팅 시퀀스, 인증 로직까지 구현했다. "오오, 폴아웃 느낌 난다!" 하고 흥분했는데... 그건 그냥 튜토리얼이었다.

이제 진짜가 시작된다. **탭 구조 확장, Admin 로그인, 그리고 CSS flexbox와의 또 다른 전쟁.**

## ⚔️ Scene 1 : DATA는 너무 심심하다 (QUESTS로 리브랜딩)

기존 DATA 탭을 보니 너무 밋밋했다. 그냥 프로젝트 목록만 덩그러니 있고, 뭐가 진행 중인지 완료된 건지 한눈에 안 들어온다.

**"AI야, DATA 탭을 QUESTS로 바꾸고 IN PROGRESS / COMPLETED 섹션으로 나눠줘. 진행 중인 프로젝트는 프로그레스 바도 넣고."**

```jsx
const inProgressProjects = [
  {
    name: 'WITCHDICE',
    description: '주사위 기반 퍼즐형 로그라이크 게임',
    progress: 10,
    // ...
  },
  {
    name: 'DAILY BREW',
    description: 'A cozy coffee shop simulation game',
    progress: 65,
    // ...
  },
];

const releasedProjects = [
  // 완료된 프로젝트들...
];
```

그리고 노란색 프로그레스 바를 추가했다. 녹색 status가 released, 노란색이 in progress.

```css
.progress-fill {
  background: linear-gradient(90deg, #ffaa00, #ff8800);
  box-shadow: 0 0 8px rgba(255, 170, 0, 0.4);
}
```

이제 "퀘스트 진행 중" 느낌이 산다! RPG 게임에서 퀘스트 로그 보는 것 같다.

## 🌪️ Scene 2 : 탭 대폭발 (LOGS, INVENTORY, CONTACT 추가)

STAT, QUESTS만 있으니 뭔가 부족했다. 내 경력, 대외활동, 연락처는 어디다 넣지?

**"AI야, 탭 3개 더 만들어줘. LOGS는 경력 타임라인, INVENTORY는 대외활동, CONTACT는 연락처."**

### LOGS 탭 - 경력 타임라인

```jsx
const logs = [
  {
    year: '2026',
    events: [
      { date: '03', title: 'PORTFOLIO-BLOG 개발', desc: '터미널 스타일 포트폴리오 웹사이트 개발' },
      { date: '01', title: 'DAILY BREW 사이드 프로젝트 시작', desc: '카페 시뮬레이션 게임 개발 시작' },
    ]
  },
  // ...
];
```

연도별로 왼쪽에 선을 그어서 타임라인 느낌을 냈다. CSS `border-left`로 간단하게 구현.

### INVENTORY 탭 - 대외활동/수상내역

```jsx
const activities = [
  {
    year: '2024',
    title: 'Global Game Jam 2024 Seoul 참가',
    type: 'GAME JAM',
    desc: '48시간 게임 개발 대회 참가...',
    link: 'https://...',
  },
];
```

타입별로 다른 색상을 적용했다. `GAME JAM`은 주황색, `EXHIBITION`은 보라색... 인벤토리 아이템처럼 각자 다른 희귀도 색상!

### CONTACT 탭 - 연락처

GitHub, Email, LinkedIn, Blog 링크를 넣었다. 클릭하면 해당 페이지로 이동.

그리고 헤더에 **UPTIME 실시간 시간 표시**도 추가했다.

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    setCurrentTime(new Date());
  }, 1000);
  return () => clearInterval(timer);
}, []);
```

유니티 `Update()` 루프 같은 느낌? 1초마다 상태를 업데이트한다.

## 🔥 Scene 3 : Admin의 습격 (빨간색 경고 모달)

숨겨진 **[ ??? ]** 버튼을 누르면 Admin 로그인 모달이 뜬다. 근데 기존 모달은 녹색이었다. Admin인데 녹색이라니, 위반감이 없다.

**"AI야, Admin 모달은 빨간색으로 해줘. 경고 느낌 나게."**

```css
.admin-modal {
  border-color: #ff4444 !important;
  box-shadow: 
    0 0 30px rgba(255, 68, 68, 0.3),
    inset 0 0 50px rgba(255, 68, 68, 0.05) !important;
}

.admin-btn {
  border: 1px solid #ff444480;
  color: #ff4444;
}
```

이제 "DO NOT ACCESS HERE" 느낌이 산다. 비밀번호 틀리면 ACCESS DENIED. 아직 Admin 대시보드는 구현 안 했지만... 곧 할 거다. 아마도.

## 💀 Scene 4 : 프로젝트 카드 레이아웃 전쟁 (flexbox... 너란 녀석)

### 1차 전투: 프로그레스바 하단 고정

IN PROGRESS 프로젝트 카드를 보니, 프로그레스바가 카드 중간에 둥둥 떠 있었다. TECH STACK이 짧으면 프로그레스바가 위로 올라가 버리는 거다.

**"AI야, 프로그레스바를 카드 하단에 고정해줘."**

```css
.project-card.clickable .project-tech {
  flex: 1; /* TECH STACK 영역이 늘어남 */
}

.project-progress {
  margin-top: auto; /* 프로그레스바를 하단으로 */
}
```

음... 됐다! 근데 TECH STACK이 너무 늘어나서 밋밋해 보인다.

### 2차 전투: TECH STACK 고정, 프로그레스바만 하단으로

**"AI야, TECH STACK은 고정하고 프로그레스바만 하단에 고정해줘."**

```css
.project-tech {
  flex-shrink: 0; /* 늘어나지 않음 */
}

.project-progress {
  margin-top: auto; /* 이것만 하단으로 */
}
```

완벽! 이제 TECH STACK은 내용만큼만 차지하고, 프로그레스바는 항상 하단에 붙어 있다.

### 3차 전투: COMPLETED QUESTS의 [ CLICK FOR DETAILS ]도 하단 고정

COMPLETED 섹션은 프로그레스바가 없다. 그래서 [ CLICK FOR DETAILS ] 텍스트가 카드 중간에 떠 있었다.

**"이것도 하단에 고정해줘."**

```css
.project-click-hint {
  margin-top: auto;
}
```

이제 모든 카드가 깔끔하게 정렬되었다. CSS flexbox... 너란 녀석, 알고 보면 어렵지 않은데 처음엔 진짜 헷갈린다. 유니티 `VerticalLayoutGroup` + `Content Size Fitter` 조합이 그립다...

**CSS flexbox, 이제 좀 알 것 같은데?**

`flex: 1`, `flex-shrink: 0`, `margin-top: auto`... 이 세 개만 알면 레이아웃 끝난다. 유니티 `Layout Group`이랑 `Content Size Fitter` 조합하는 거랑 비슷하네.

그리고 `display: grid`도 써봤다. 프로젝트 카드 그리드.

```css
.projects-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 20px;
}
```

이거 `auto-fill`이 진짜 편하다. 화면 크기에 따라 자동으로 컬럼 개수 조절해준다. 유니티 `GridLayoutGroup`이랑 비슷한데, 반응형까지 자동으로 됨.
