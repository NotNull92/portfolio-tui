## 폐기 안내

이 글은 클라이언트에 민감한 편집 화면과 접근 단서를 포함하는 실험 기록이어서 폐기했다.

현재 포트폴리오는 정적 소개 화면으로 유지하며, 프로젝트 데이터는 코드 리뷰를 거쳐 배포 시점에 반영한다. 브라우저에서 직접 데이터를 수정하는 별도 화면은 사용하지 않는다.
